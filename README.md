# DEVOS Browser Runtime

DEVOS Browser Runtime is a browser-independent, AI-assisted, governed automation runtime.

> DEVOS may use Chrome/CDP, Playwright, Firecrawl, BrowserAct, Edge, and other browser technologies deeply, but only through dedicated adapters/capability modules. DEVOS Core must remain independent of any single implementation.

GitHub is source control, documentation, CI/CD, and release distribution only. The installed DEVOS Runtime is the actual execution engine.

## Phase 0 status

This repository is being initialized with architecture docs, capability abstractions, protocol models, governance skeleton, checkpoint skeleton, synthetic portal fixtures, and CI.
